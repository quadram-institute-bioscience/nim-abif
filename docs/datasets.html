Validation datasets

This page lists datasets used to test the nim-abif suite. These datasets contain real sequencing traces and expected results. They help check parsing, conversion, alignment, reporting, and regression behavior.

Dataset 5865470 Sanger AB1 traces from the SangeR paper, used to test hotspot screening with abiscreen. Dataset 4968940 AB1 traces from Zenodo record 4968940, used by the test suite for trace parsing and command-line behavior.

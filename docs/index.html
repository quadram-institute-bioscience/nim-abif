ABIF tools for Nim

nim-abif is a Nim library and command-line toolkit for ABIF (Applied Biosystems Information Format) files from Sanger capillary sequencing instruments.

Library API Validation dataset GitHub repository

Features

  • Parse .ab1 and .fsa trace files
  • Extract sequences, quality values, sample names, and metadata tags
  • Export traces to FASTA and FASTQ formats
  • Trim low-quality bases and merge paired forward/reverse traces
  • Render chromatograms as SVG images
  • Screen hotspot panels and write CSV, VCF, and HTML reports

Tools

abi2fq

Convert ABIF trace files to FASTQ, with optional quality trimming.

  • Convert ABIF trace files to FASTQ format
  • Trim low-quality bases from sequence ends
  • Configure sliding window size and quality threshold
  • Output to STDOUT or to a file

Usage examples

# Basic conversion
abi2fq trace.ab1 output.fq
# With quality trimming (window size 15, quality threshold 25)
abi2fq --window=15 --quality=25 trace.ab1 output.fq
# Skip quality trimming
abi2fq --no-trim trace.ab1 output.fq
abimerge

Merge overlapping traces using Smith-Waterman alignment.

abimerge trace_F.ab1 trace_R.ab1
abichromatogram

Render ABIF traces as SVG chromatograms for inspection or reports.

abichromatogram file.ab1 -o image.svg -s 500 -e 1000 --width 1600

The output can be in HTML format and SVG format.

abimetadata

Inspect ABIF metadata tags from trace files.

abimetadata trace_F.ab1
abiscreen

Batch hotspot mutation screening across many .ab1 traces. It aligns each trace against a reference panel, classifies the hotspot state, and writes CSV, VCF, and HTML reports with chromatogram evidence.

abiscreen -i traces/ -p targets.tsv -r refs.fa -o results/

Installation

Install with Nimble:

nimble install abif

Or install the packaged command-line tools from Bioconda:

conda install -c bioconda nim-abif
